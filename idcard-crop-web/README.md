# 身份证智能裁剪工具 (ID Card Smart Cropper)

纯前端 Web 工具，自动检测身份证区域、透视矫正、方向校正。图片不上传服务器，全部本地处理。

## 功能

- **自动检测**：多策略角点检测（Canny 边缘、Otsu 阈值、饱和度分析、亮度分析）
- **智能评分**：自动验证检测区域是否为身份证（亮度、纹理、宽高比）
- **透视矫正**：将倾斜/透视变形的身份证矫正为标准矩形
- **方向校正**：自动识别正反面方向（利用人脸照片位置检测）
- **手动调整**：自动检测失败时可拖拽四角点手动指定区域
- **批量处理**：支持多图上传批量裁剪
- **ZIP 下载**：批量结果打包下载
- **ONNX 模型扩展**：预留轻量模型接口，可加载 ONNX 分割模型提升复杂场景检测率

## 技术栈

- OpenCV.js 4.9.0 - 图像处理核心
- ONNX Runtime Web 1.17.0 - 可选模型推理
- JSZip 3.10.1 - 批量下载
- 纯 HTML/CSS/JS，无需构建工具

## 使用方法

1. 打开 `index.html`（或部署到任意静态托管）
2. 拖拽或选择身份证照片
3. 自动检测完成后预览裁剪结果
4. 如需调整，拖拽左侧蓝色角点
5. 点击"下载当前图片"或"下载全部"

## 本地开发

```bash
cd idcard-crop-web
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 检测准确率

在 22 张真实样本测试中：
- 自动检测率：~91%
- 高质量裁剪率：~70%
- 配合手动调整：100%

## 可选：加载 ONNX 模型

```javascript
// 加载 U2-Net 或类似的前景分割模型
await detector.loadModel('path/to/model.onnx', 320);
// 之后自动检测会优先使用模型，提升复杂背景检测率
```
